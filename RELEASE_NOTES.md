# DanceAdmin 1.4.0b (сборка 173) — бета

Предварительный выпуск (Pre-release). Последний обычный выпуск — 1.3.0 (сборка 168): если нужна проверенная версия, берите его.

**Скачать:**
- `DanceAdmin_Setup_1.4.0b-173.exe` — установщик (рекомендуется);
- `DanceAdmin_1.4.0b-173_portable.zip` — переносная версия, без установки (exe, лицензия, руководство).

Windows 10/11 x64, .NET внутри. Данные — в `C:\ProgramData\DanceAdmin\`. Установка поверх прежней версии сохраняет базу (перед обновлением делается резервная копия).

## Что нового по сравнению с бетой 170
- **Снимок рабочего компьютера:** рабочий компьютер сохраняет полную копию в папку (удобно — в облаке) при закрытии смены, при выходе и раз в час; на другом компьютере её открывают только для просмотра — без перезапуска и пароля, новый снимок открывается сам. Кнопка «Смотреть рабочий снимок» вверху, «Снимок: ЧЧ:ММ ⟳» в строке внизу — сохранить снимок сейчас может любой сотрудник. Смотреть — директор и роли с новым правом «Снимок рабочего компьютера».
- **Расписание:** изменение шаблона с будущей даты — до неё действует прежнее расписание; в журнале видно, с какой даты новое и что поменялось.
- **Экспорт и импорт** переносят «Правила и ставки» и минимальную оплату тренеру; архивные залы и группы без галочки «вместе с архивными» не выгружаются.
- **Посещения:** в «Занятиях дня» виден зал.
- **Настройки:** минимум тренеру и минуты отметки пустые и неактивные, когда выключены; число направлений; неактивные группы абонементов — серым; «типов: N» у групп — столбиком, в подсказке типы с новой строки.
- Строка состояния внизу — все надписи на одной линии, с разделителями.

## Исправления
- Возврат с «Уменьшить число занятий на» принимает только число от 1 до оставшихся занятий (отрицательное число добавляло занятия).
- В группе клиентов с ценами больше не появляется пустая строка цены.
- В старых отчётах смены способ оплаты показывается в колонке «Способ», а не в примечании.
- Правка шаблона «с сегодня» больше не сдвигает дату начала шаблона.

## Важно
- Бета приходит в программе только тем, у кого в «О программе» отмечено «Сообщать о бета-версиях».
- Делайте резервные копии (Настройки → Резервные копии).
- Программа не подписана сертификатом: Windows SmartScreen покажет предупреждение — «Подробнее» → «Выполнить в любом случае».
- Об ошибках и пожеланиях — в Issues.

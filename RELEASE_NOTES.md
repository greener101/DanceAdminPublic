# DanceAdmin 1.4.0b (сборка 178) — бета

Предварительный выпуск (Pre-release). Последний обычный выпуск — 1.3.0 (сборка 168): если нужна проверенная версия, берите его.

**Скачать:**
- `DanceAdmin_Setup_1.4.0b-178.exe` — установщик (рекомендуется);
- `DanceAdmin_1.4.0b-178_portable.zip` — переносная версия, без установки (exe, лицензия, руководство).

Windows 10/11 x64, .NET внутри. Данные — в `C:\ProgramData\DanceAdmin\`. Установка поверх прежней версии сохраняет базу (перед обновлением делается резервная копия).

## Что нового по сравнению с бетой 176
- **Бессрочный абонемент:** кнопка «∞ Бессрочно» в карточке клиента — вместо даты окончания «бессрочно», абонемент действует, пока не кончатся занятия; «Вернуть срок» снова даёт дату окончания.
- **Перенос данных:** кнопка «В архив» в строке клиента и вкладка «Архив»; красный значок ⚠ у клиентов, чьи данные ещё не перенесены — отметить такого клиента можно после переноса, «Сделать сейчас» открывает перенос прямо при отметке.
- **«Что нового»:** после обновления каждый сотрудник один раз видит окно с новыми возможностями — только то, что появилось после версии, которую он видел.
- **Права:** новое право «Настройки → Обновления» (обновлять программу может не только директор); с правом «Пользователи и права» можно создавать, переименовывать и удалять роли.
- **Логин и пароль:** логин — английские буквы, цифры, «_» и «.»; пароль — английские буквы, цифры, «#» и «_». Прежние логины и пароли работают до первой смены.
- «Закрытие смены» — и в меню у имени вверху справа; причины заморозки настраиваются в «Расширенных»; галочки переключаются только щелчком по квадратику.

## Важно
- Бета приходит в программе только тем, у кого в «О программе» отмечено «Сообщать о бета-версиях».
- Если в «Расширенных» включён «Перенос данных», после обновления у всех ещё не перенесённых клиентов появится значок ⚠, и отметить их можно будет после переноса.
- Делайте резервные копии (Настройки → Резервные копии).
- Программа не подписана сертификатом: Windows SmartScreen покажет предупреждение — «Подробнее» → «Выполнить в любом случае».
- Об ошибках и пожеланиях — в Issues.

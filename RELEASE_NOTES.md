# DanceAdmin 1.0.0b2 (сборка 117) — бета 2

Вторая публичная бета программы учёта для танцевальной / фитнес-студии.

**Скачать:**
- `DanceAdmin_Setup_1.0.0b2-117.exe` — установщик (рекомендуется);
- `DanceAdmin_1.0.0b2-117_portable.zip` — переносная версия, без установки (exe, лицензия, руководство).

Windows 10/11 x64, .NET внутри. Данные — в `C:\ProgramData\DanceAdmin\`. Установка поверх 1.0.0b сохраняет базу (обновляется автоматически, перед обновлением делается резервная копия).

## Что нового по сравнению с 1.0.0b (сборка 104)
- **Смены администраторов:** полноценно работает один администратор; другой — через 30 минут после выхода первого (настройка), смена первого останавливается, отчёт за неё он оформит при следующем входе. Директор может закрыть смену за администратора. Внизу окна — все открытые смены, предупреждение о смене 12 ч и больше, «Смена: закрыта».
- **Касса:** «Нал в кассе» — то, что реально в кассе, по каждому сотруднику; перенос наличных в сейф; «Смену закрывать не нужно», если изменений не было.
- **Отчёты смен:** долги в итогах, столбцы «Продано на / В долг / Получено», лист А4, печать и PDF, подбор размера шрифта.
- **Зарплата:** уточнение времени администратора при расчёте; «Сформировать зарплату» не заканчивает смену.
- **Посещения и клиенты:** «Параллельно», фильтр «Взрослые / Дети», правила отметки, история клиента в PDF, телефоны в едином формате.
- **Настройки:** свои роли, экспорт по выбору, подробности импорта, удаление типов абонементов, смена пароля, значок «DA».

## Это бета
- Возможны ошибки — регулярно делайте резервные копии (Настройки → Резервные копии, «вторая папка» на флешку или в облако).
- Программа не подписана сертификатом: Windows SmartScreen покажет предупреждение — «Подробнее» → «Выполнить в любом случае».
- Об ошибках и пожеланиях — в Issues.

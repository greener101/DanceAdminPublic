# DanceAdmin 1.4.0b (сборка 176) — бета

Предварительный выпуск (Pre-release). Последний обычный выпуск — 1.3.0 (сборка 168): если нужна проверенная версия, берите его.

**Скачать:**
- `DanceAdmin_Setup_1.4.0b-176.exe` — установщик (рекомендуется);
- `DanceAdmin_1.4.0b-176_portable.zip` — переносная версия, без установки (exe, лицензия, руководство).

Windows 10/11 x64, .NET внутри. Данные — в `C:\ProgramData\DanceAdmin\`. Установка поверх прежней версии сохраняет базу (перед обновлением делается резервная копия).

## Что нового по сравнению с бетой 173
- **Руководство администратора:** окно почти на всю высоту экрана, слева — оглавление: щелчок по разделу переходит к нему, текущий раздел подсвечен.
- **Снимок рабочего компьютера:** снимки нескольких рабочих компьютеров в одной папке не смешиваются — в имени файла название компьютера (поле «Название этого компьютера»), у каждого хранятся свои 3 последних; если компьютеров несколько, на другом компьютере можно выбрать, чей снимок смотреть. Кнопка «ⓘ Инструкция» в «Настройки → Расширенные».
- **Справочники:** строки групп абонементов, залов, групп клиентов и возрастных категорий подсвечиваются при наведении, щелчок — изменить; в «Группах клиентов» «клиентов: N» и «добавить в группу» — ровными столбиками.
- **Посещения → «Занятия дня»:** зал — строкой под тренером, зелёным — только «● сейчас».

## Важно
- Бета приходит в программе только тем, у кого в «О программе» отмечено «Сообщать о бета-версиях».
- Снимки, сохранённые версией 173 (без названия компьютера), удаляются при первом новом сохранении — это нормально.
- Делайте резервные копии (Настройки → Резервные копии).
- Программа не подписана сертификатом: Windows SmartScreen покажет предупреждение — «Подробнее» → «Выполнить в любом случае».
- Об ошибках и пожеланиях — в Issues.

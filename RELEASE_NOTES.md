# DanceAdmin 1.1.0b (сборка 121)

Новая бета-версия программы учёта для танцевальной / фитнес-студии.

**Скачать:**
- `DanceAdmin_Setup_1.1.0b-121.exe` — установщик (рекомендуется);
- `DanceAdmin_1.1.0b-121_portable.zip` — переносная версия, без установки (exe, лицензия, руководство).

Windows 10/11 x64, .NET внутри. Данные — в `C:\ProgramData\DanceAdmin\`. Установка поверх прежней версии сохраняет базу (обновляется автоматически, перед обновлением делается резервная копия).

## Что нового по сравнению с 1.0.0b2 (сборка 117)
- **Группы клиентов** с особыми условиями: скидка от обычной цены или своя цена абонемента, ставка тренеру (₽, −₽ или % от ставки); наполнение групп «параллельно»; **возрастные категории** — свои, с быстрым назначением.
- **Группы абонементов** (фильтр при продаже, группа по умолчанию), **доплата за посещение** по направлению, **заморозка у каждого типа**.
- **Зарплата по ролям:** повременная / за отметки / фиксированная, ставки ролей и свои ставки сотрудников; учёт времени по ролям — по сменам (точно по минутам или с округлением, остаток переносится) или «сотрудник проставляет сам» (ползунок 0–12 ч).
- **Смены** могут идти у нескольких сотрудников одновременно.
- **Справочники по вкладкам**, подсказки ⓘ, наборы прав «Полный доступ / Стандартный / Базовый / Только просмотр».
- **Импорт / экспорт:** zip-архивы, справочники целиком; **восстановление из любого файла копии** с показом содержимого.
- **Печать:** расписание занятий и прайс абонементов — лист А4 и PDF.
- Абонементы больше 24 занятий — «10/72»; кружки по 8 в ряду.

## Это бета
- Возможны ошибки — регулярно делайте резервные копии (Настройки → Резервные копии, «вторая папка» на флешку или в облако).
- Программа не подписана сертификатом: Windows SmartScreen покажет предупреждение — «Подробнее» → «Выполнить в любом случае».
- Об ошибках и пожеланиях — в Issues.

# DanceAdmin 1.1.0 (сборка 131)

Выпуск 1.1.0 — программа учёта для танцевальной / фитнес-студии.

**Скачать:**
- `DanceAdmin_Setup_1.1.0-131.exe` — установщик (рекомендуется);
- `DanceAdmin_1.1.0-131_portable.zip` — переносная версия, без установки (exe, лицензия, руководство).

Windows 10/11 x64, .NET внутри. Данные — в `C:\ProgramData\DanceAdmin\`. Установка поверх прежней версии сохраняет базу (обновляется автоматически, перед обновлением делается резервная копия).

## Что нового по сравнению с 1.1.0b (сборка 121)
- **Индивидуальные занятия:** бессрочный абонемент на одно занятие, только на индивидуальных направлениях; на занятие — один человек или (по галочке) группа; продажа прямо при отметке.
- **Касса:** при закрытии смены учитывается остаток с прошлой смены; выбор «за сотрудником» или «общая касса» (Настройки → Расширенные).
- **Зарплата сотрудников:** больше 24 ч в одном расчёте, «сотрудник проставляет сам» без отметок, удержание за снятые отметки, работа после закрытия смены снова запускает время.
- **Excel (.xlsx):** отчёты смен, журнал, расписание и абонементы; отчёты в папку — в выбранных форматах (картинка / текст / Excel).
- **Печать расписания** на альбомном листе: сетка недели отдельно, дни — с новой страницы; без индивидуальных занятий по умолчанию.
- **Резервная копия одним zip:** база, фото и логотип; подсказка про облако (Яндекс Диск, Облако Mail.ru, OneDrive).
- **Права:** наборы прав редактируются («Обновить»), новое право «Абонементы: корректировка»; полные тёзки клиентов не сохраняются.
- **Внешний вид:** цветные смайлики в сообщениях, цвета ячеек расписания на выбор, зелёная гамма с тёмным меню, окно входа шире.
- **Исправления по итогам тестирования:** безопасность пароля директора, откат импорта, «Разморозить и отметить», отмена первой отметки, журнал восстановления, ввод времени в расчёте зарплаты.

## Важно
- Программа не подписана сертификатом: Windows SmartScreen покажет предупреждение — «Подробнее» → «Выполнить в любом случае».
- Делайте резервные копии (Настройки → Резервные копии, «вторая папка» на флешку или в облако).
- Об ошибках и пожеланиях — в Issues.

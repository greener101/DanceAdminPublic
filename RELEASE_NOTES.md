# DanceAdmin 1.4.0b (сборка 170) — бета

Предварительный выпуск (Pre-release). Последний обычный выпуск — 1.3.0 (сборка 168): если нужна проверенная версия, берите его.

**Скачать:**
- `DanceAdmin_Setup_1.4.0b-170.exe` — установщик (рекомендуется);
- `DanceAdmin_1.4.0b-170_portable.zip` — переносная версия, без установки (exe, лицензия, руководство).

Windows 10/11 x64, .NET внутри. Данные — в `C:\ProgramData\DanceAdmin\`. Установка поверх прежней версии сохраняет базу (перед обновлением делается резервная копия).

## Что нового по сравнению с 1.3.0
- **Отметка без ограничения по времени** (Настройки → Расширенные): по желанию клиента можно отметить в любой момент, в том числе на прошлом занятии, если забыли.
- **Блокировка программы:** замок вверху справа и Ctrl+L — вход по паролю, смена не закрывается.
- **Зарплата тренеров:** коррекция ставки для тренера (± % или ± ₽), минимальная оплата за занятие (доплата пересчитывается при доотметке), щелчок по строке истории начислений показывает детали: кто отмечен, ставки, доплата. Новые права «Тренеры → Изменение зарплаты».
- **Отчёт смены:** колонка «Способ» (наличные, карта, перевод, с баланса) у абонементов и зарплаты.
- **Справочники:** архив типов абонементов («Переместить в архив», «Вернуть из архива», удалить можно только никем не купленный тип); у групп абонементов — подсказка со списком типов.
- **Назначения расходов** настраиваются в «Расширенных».
- «● сейчас» на главной — только пока занятие идёт; кнопка «Аренда зала» на главной.

## Исправления
- Долг клиента после аннулирования оплаты с переплатой считается верно.
- Автоблокировка при простое снова срабатывает.
- В истории тренера «За период: начислено» учитывает доплату до минимума.
- Права ролей: щелчок по «квадратику» группы отмечает все подпункты.
- В режиме «Только просмотр» окна изменений не открываются и объясняют почему.
- Помощник исправляет опечатки и в словах-примерах; мелкие исправления надписей.

## Важно
- Бета приходит в программе только тем, у кого в «О программе» отмечено «Сообщать о бета-версиях».
- Делайте резервные копии (Настройки → Резервные копии).
- Программа не подписана сертификатом: Windows SmartScreen покажет предупреждение — «Подробнее» → «Выполнить в любом случае».
- Об ошибках и пожеланиях — в Issues.

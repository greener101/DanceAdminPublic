# DanceAdmin 1.3.0b (сборка 163) — бета

Предварительный выпуск (Pre-release). Последний обычный выпуск — 1.2.0 (сборка 159): если нужна проверенная версия, берите его.

**Скачать:**
- `DanceAdmin_Setup_1.3.0b-163.exe` — установщик (рекомендуется);
- `DanceAdmin_1.3.0b-163_portable.zip` — переносная версия, без установки (exe, лицензия, руководство).

Windows 10/11 x64, .NET внутри. Данные — в `C:\ProgramData\DanceAdmin\`. Установка поверх прежней версии сохраняет базу (перед обновлением делается резервная копия).

## Что нового по сравнению с 1.2.0
- **Поле «Группа» в окне «Новый клиент / Изменить клиента»** — под возрастной категорией. Обычно клиент в одной группе: список с вариантом «— без группы —», выбор другой группы переводит клиента в неё. Если директор разрешил несколько групп — кнопки с названиями групп и «Без группы».
- **Отчёт смены без пустых разделов:** «Иная оплата» и «Иной расход» появляются, только если в них есть записи; номера следующих разделов сдвигаются.
- **О новых версиях программа сообщает при каждом входе и каждые 4 часа**, а не раз в сутки (раньше новая версия могла не показаться до следующего дня).

## Исправления
- Импорт клиентов больше не ставит «Взрослые» тем, у кого в файле нет возрастной категории: после выгрузки и загрузки «— не указана —» остаётся «— не указана —».
- Пункт «Перенос данных» появляется в меню сразу после импорта настроек (раньше — только после перезапуска).

## Важно
- Бета приходит в программе только тем, у кого в «О программе» отмечено «Сообщать о бета-версиях».
- Делайте резервные копии (Настройки → Резервные копии).
- Программа не подписана сертификатом: Windows SmartScreen покажет предупреждение — «Подробнее» → «Выполнить в любом случае».
- Об ошибках и пожеланиях — в Issues.

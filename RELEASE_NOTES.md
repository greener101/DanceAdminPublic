# DanceAdmin 1.2.0b (сборка 143) — бета

Предварительный выпуск с новыми возможностями. Последний обычный выпуск — 1.1.0 (сборка 131).

**Скачать:**
- `DanceAdmin_Setup_1.2.0b-143.exe` — установщик (рекомендуется);
- `DanceAdmin_1.2.0b-143_portable.zip` — переносная версия, без установки (exe, лицензия, руководство).

Windows 10/11 x64, .NET внутри. Данные — в `C:\ProgramData\DanceAdmin\`. Установка поверх прежней версии сохраняет базу (обновляется автоматически, перед обновлением делается резервная копия).

## Что нового по сравнению с 1.1.0 (сборка 131)
- **Помощник и руководство:** значок «?» (F1) — вопрос своими словами, помощник предлагает подходящие темы; руководство переписано простым языком, по шагам, его можно свернуть вниз окна.
- **Продажа:** скидка с причиной (по праву роли «Скидка при продаже»), общий абонемент на двоих.
- **Аренда зала** с проверкой занятости и отметкой в расписании; полный возврат освобождает зал.
- **Расписание:** фильтр по направлениям, печать и PDF того, что выбрано.
- **Аналитика:** графики — выручка по месяцам за год с выбором года, по тренерам и залам, новые и ушедшие клиенты, загрузка залов, посещения по дням и часам.
- **Telegram:** отправка отчёта смены всем получателям; формат (PDF, Excel, текст) — в «Информере»; пошаговая инструкция; токен хранится зашифрованным и показывается частично.
- **Перенос данных** из старого учёта: абонементы, группы и общий долг клиента.
- **Резервные копии:** перед восстановлением видно, что пропадёт; номера отчётов не повторяются; копии хранятся по дням, неделям и месяцам; при повреждённой базе — пошаговая инструкция, восстановление работает и поверх повреждённой базы.
- **Пользователи:** свой логин можно сменить, директор может удалить сотрудника, который ещё не работал; режим «Только просмотр» показывает все настройки.
- **Экспорт** расширенных настроек и наборов прав.
- **Исправления по итогам тестирования** и много мелких улучшений интерфейса.

## Важно
- Это бета-версия: возможны недоработки. Делайте резервные копии (Настройки → Резервные копии, «вторая папка» на флешку или в облако).
- Программа не подписана сертификатом: Windows SmartScreen покажет предупреждение — «Подробнее» → «Выполнить в любом случае».
- Токен Telegram зашифрован ключом компьютера: после переноса базы на другой компьютер его нужно вписать заново.
- Об ошибках и пожеланиях — в Issues.
